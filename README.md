# The Earth Information Jukebox

Our project for the NASA Space Apps Challenge 2026. The Earth Jukebox pairs NASA Earth Information Center visualizations, made by the Scientific Visualization Studio, with music generated live from the data. Pick a dataset and its video plays while the sound follows along: warm oceans, growing city lights, lightning bursts and drifting CO₂ plumes each get their own musical voice. An explore mode lets you move around the map with the mouse or arrow keys and hear the value at that point, so blind and low-vision users can explore Earth science by ear.

## Team

- **Person 1, Data & Analysis**: downloads the SVS media, extracts frames, computes the per-frame features in Python and publishes them as JSON.
- **Person 2, Audio Engine**: Tone.js sound presets for each dataset, musical scales and the `probe(x, y)` used in explore mode.
- **Person 3, UI & Accessibility**: the jukebox interface, keyboard explore mode, screen-reader support, documentation and the demo video.

## Run it locally

It's a static site, so no build step is needed. From the repo root:

```bash
python3 -m http.server
```

Then open <http://localhost:8000>.

## Data

- `public/data/index.json` lists the datasets.
- `public/data/<dataset>/features.json` holds the per-frame features. These are mock data for now, generated by `python3 scripts/make_mock.py`.
- `python3 scripts/validate.py` checks every file against the contract.

The format is described in [docs/data-contract.md](docs/data-contract.md). Sources and credits are in [docs/sources.md](docs/sources.md).
